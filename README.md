# Admss-client

Admss-client — это клиентское приложение, предназначенное для управления административными задачами.

## Структура проекта

- `src/` — исходный код приложения
- `public/` — статические файлы
- `package.json` — зависимости и скрипты
- `README.md` — описание проекта

## Установка

1. Клонируйте репозиторий:
   ```
   git clone <URL-репозитория>
   ```
2. Перейдите в папку проекта:
   ```
   cd Admss-client
   ```
3. Установите зависимости:
   ```
   npm install
   ```

## Запуск

Для запуска приложения используйте команду:

```
npm start
```

## Сборка

Для сборки приложения используйте:

```
npm run build
```

## Авторизация

Для входа в приложение используйте ваши учетные данные:

- **Username** — имя пользователя
- **Password** — пароль

Введите username и password на странице входа для получения доступа к функционалу приложения.
