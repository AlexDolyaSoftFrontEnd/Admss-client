# Admss-client

Это клиентское приложение, предназначенное для управления административными задачами.

## Установка

1. Клонируйте репозиторий:
   ```
   git clone <URL-репозитория>
   ```
2. Перейдите в папку проекта:
   ```
   cd Admss-client
   ```
3. Установите зависимости:
   ```
   npm install
   ```

## Запуск

Для запуска приложения используйте команду:

```
npm start
```

## Сборка

Для сборки приложения используйте:

```
npm run build
```

## Авторизация

Для входа в приложение используйте учетные данные:

- **mobile2**
- **Password**
